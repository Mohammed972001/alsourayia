# UI contract — for every agent that writes UI here

This project («مفروشات العمودي») is planned and built with spec-kit. Read
`.specify/memory/constitution.md` and `docs/adr/0002-identity-gold-and-white.md` before touching `src/`.

- **Server Components by default.** `'use client'` only for real interactivity, as a small leaf.
  Indexable text stays in the server-rendered HTML.
- **Tokens only.** Colours, type sizes, space, radius, shadows and timing come from
  `src/styles/tokens.css`, generated by `design-system/build-tokens.mjs` (`npm run tokens`). No hex
  in components or stylesheets outside the generator.
- **RTL logical properties only** (`inset-inline-start`, `padding-inline-end`, `text-align: start`).
- **No hard-coded copy or facts.** Copy lives in `src/content/`; business facts in
  `src/content/site.ts`. Never invent a number or claim; leave the fact `null` and add it to
  `docs/owner-checklist.md`.
- **Photos** go through `scripts/media.mjs` and the `Photo` component. `media-src/tmp/` photos are
  temporary and never ship on the live site.
- **Icons** are inline SVG (`src/components/Icon.tsx`). No emoji anywhere.
- **Semantics and a11y:** one `<h1>` per page, correct heading order, `<a href>` for navigation,
  `<button>` for actions, visible `:focus-visible`, touch targets ≥ 44 px, `prefers-reduced-motion`,
  Arabic `alt` text.
- **Done means:** `npm run lint`, `npm run typecheck`, `npm run build`, `npm run check` pass, and the
  page was looked at in a browser at 390 px and 1440 px.
